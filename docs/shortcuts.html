iOS Shortcuts built for profile control and fast action.

The following shortcuts are examples of how to use PetDNS with Siri and the Shortcuts app. These shortcuts are designed to be quickly added to your library and ready for use immediately. Tap any title below to add the shortcut directly to your library.

Shortcut Requests

Have a shortcut request or want to see your own shortcut shown here? Contact me to share your idea!

Deny/Allow Domain from Browser

Add the current page domain to the selected profile’s allowlist or denylist directly from Safari and the iOS Share Sheet. Useful for fast troubleshooting and targeted filtering.

Check NextDNS Connection

Validate your current NextDNS connection and confirm which profile is active. Designed for troubleshooting and use as an actionable step inside larger automations.

AI Overview of Profile (iOS 26)

Generate a natural-language summary of the current profile configuration using Apple Intelligence. Ideal for fast review and quick understanding of complex profile state. Uses Apple's Private Cloud Compute by default but can be adjusted inside the Shortcuts app.

AI Recommendations for Profile (iOS 26)

Use Apple Intelligence to generate recommendations based on the profile’s current settings. Helpful for reviewing configuration intent and exploring optimization ideas. Uses Apple's Private Cloud Compute by default but can be adjusted inside the Shortcuts app.

Update Profile Linked IP

Automate updates to a profile’s linked IP address. Useful for managed or dynamic networking situations. When setting up the Shortcut, you will be prompted to enter your Profile ID and Update Token. These can be found inside PetDNS by navigating to "Setup on your Devices" in the Profile tab.

Bulk Domain Import

Import a domain list from a text file into either the allowlist or denylist for a selected profile. Designed for larger-scale housekeeping and repeatable blocklist management. If you do not have an easy way to create a text file, you can use the "Create Domain Import TXT File" shortcut to create one. Requires PetDNS Pro.

Create Domain Import TXT File

This shortcut helps you create a text file containing a list of domains that can be used with the "Bulk Domain Import" shortcut. To create the file, edit the shortcut and enter the domains you want to import, then run the shortcut.
