iOS Shortcuts built for profile control and fast action.

PetDNS shortcuts are designed for users who want to move faster: add domains from Safari, inspect connection state, update linked IP values, and bulk-manage allowlist and denylist changes without leaving the iOS workflow.

Workflow

Trigger actions from Safari, Siri, or your own custom automation flows without needing a full browser session.

Control

Change profile behavior from quick actions, not just from dashboards — useful for managed profiles, troubleshooting, and rapid policy updates.

Automation

Use Apple’s Shortcuts ecosystem to connect the app into broader iPhone workflows, device checks, and operational tasks.

Deny/Allow Domain from Browser

Add the current page domain to the selected profile’s allowlist or denylist directly from Safari and the iOS Share Sheet. Useful for fast exception handling and targeted filtering.

Check NextDNS Connection

Validate your current NextDNS connection and confirm which profile is active. Designed for troubleshooting and use as a reusable step inside larger automations.

AI Overview of Profile

Generate a natural-language summary of the current profile configuration using Apple Intelligence. Ideal for fast review and quick understanding of complex profile state.

AI Recommendations for Profile

Use Apple Intelligence to generate recommendations based on the profile’s current settings. Helpful for reviewing configuration intent and exploring optimization ideas.

Update Profile Linked IP

Automate updates to a profile’s linked IP address with a prompt for the profile ID and update token. Useful for managed or dynamic networking situations.

Bulk Domain Import

Import a domain list from a text file into either the allowlist or denylist for a selected profile. Designed for larger-scale housekeeping and repeatable blocklist management.

Create Domain Import TXT File

Generate a domain list in a format ready for import. This gives you a repeatable path for curating lists before bulk import into your configured profile.

More shortcuts are planned as the app grows and the automation surface expands.
