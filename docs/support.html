Support and Feedback

PetDNS is built to be transparent and practical. If something is broken, if a feature is missing, or if you want to suggest a workflow, the best way to reach the project is through the public issue tracker.

GitHub

The best place to report bugs, request features, or discuss a problem is the project issue tracker. Public issues make it easier to track and fix problems in a way that helps everyone.

Reddit

If you prefer to reach out without a GitHub account, you can contact me on Reddit at u/Cold-Weight951.

Email

For direct contact, email PetDNSApp@Outlook.com.

PetDNS values privacy and does not collect tracking data from the app. That means there is no automated feedback loop showing which features people use most or which problems are common. Your feedback matters, and it is critical for improving the app and keeping it aligned with how people actually use it.
